# evals

These are the evaluation harnesses, corpora, and scored runs for Mumwelt.

**Heads up: this is early, rough, and known to be suboptimal.** The questions,
gold answers, scoring rubrics, and runners here were built quickly to get *some*
signal, not to be a rigorous or stable benchmark. Expect noisy scores, uneven
coverage, gaps in the gold sets, and harnesses that need cleanup. Treat results
as directional rather than authoritative.

We want to make this much better — and **contributions are very welcome.**
Better questions, cleaner gold answers, more principled scoring, reproducible
runners, and documentation of what "good" looks like would all help. If you're
interested, open an issue or PR.

See [`DESIGN.md`](./DESIGN.md) for the current design notes.
